Mario Kart Anti-Bagging Research Lab

FILES
- index.html
- styles.css
- app.js.txt

IMPORTANT
ChatGPT environments may block or hide .js downloads, so the JavaScript is packaged as app.js.txt.

TO RUN THE LAB
1. Extract this ZIP.
2. Rename:
      app.js.txt
   to:
      app.js
3. Keep index.html, styles.css, and app.js in the same folder.
4. Open index.html in a normal browser.

If your browser restricts local file scripts, host the extracted folder with GitHub Pages, Netlify, Vercel, or a simple local web server.
